# AI Financial Fraud Detection System

# Project Overview

AI Financial Fraud Detection System is a Machine Learning-based web application that helps identify fraudulent financial transactions and detect spam SMS messages. The system uses trained machine learning models to analyze data and provide real-time predictions through a user-friendly web interface.

This project demonstrates the practical implementation of Artificial Intelligence, Machine Learning, Data Processing, and Full-Stack Web Development using Python and Flask.

# Features

# Financial Fraud Detection

* Detects fraudulent financial transactions
* Real-time fraud prediction
* Machine Learning-based classification

# SMS Spam Detection

# How It Works

# Financial Fraud Detection

1. User enters transaction information.
2. Data is processed and cleaned.
3. Machine Learning model analyzes the transaction.
4. System predicts whether the transaction is fraudulent or legitimate.

# SMS Spam Detection

1. User enters an SMS message.
2. Text is transformed using a trained vectorizer.
3. Machine Learning model evaluates the message.
4. Result is displayed as Spam or Not Spam.
